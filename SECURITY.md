# Security Policy

## Supported Versions

Security updates are provided for the latest minor and patch versions of the active release branch.

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |
| < 0.1   | :x:                |

---

## Reporting a Vulnerability

The Orchaterm team takes the security of our users seriously. If you believe you have found a security vulnerability in Orchaterm, please do **not** open a public GitHub issue.

Instead, please report vulnerabilities privately using GitHub Security Advisories:
1. Navigate to the [Security Advisories](https://github.com/anasalaqeel/orchaterm/security/advisories) page of the repository.
2. Click **Report a vulnerability**.
3. Provide detailed steps to reproduce the issue, including environment details and any potential exploit scenarios.

### What to Expect

- **Acknowledgment**: We aim to acknowledge vulnerability reports within 48 hours.
- **Assessment**: We will investigate and verify the vulnerability, keeping you informed of our progress.
- **Resolution**: Once resolved, we will release a security patch and credit you for the responsible disclosure (unless you prefer to remain anonymous).

Thank you for helping keep Orchaterm and its users safe!
